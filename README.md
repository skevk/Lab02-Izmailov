# ПР2. Ответы на контрольные вопросы

1. double хранит число в
двоичном виде, и некоторые "простые" на вид десятичные дроби (например, 0.1) не
могут быть представлены в двоичной системе абсолютно точно — накапливается
крошечная погрешность. Для физических расчётов это не страшно, но при работе с
деньгами копейка расхождения — уже баг. decimal устроен так, что подобных проблем
не возникает.

2. Если результат не помещается в
границы типа, значение "оборачивается" по кругу заново от минимума.

3. Тип переменной определяется один раз при объявлении и больше не меняется.Компилятор определяет тип переменной, объявленной через var во время компиляции.

4. Console.ReadLine() всегда возвращает string, независимо от того,
что ввёл пользователь.

5. int.Parse: исключение FormatException, программа упадёт с
ошибкой 
int.TryParse: Не упадёт. Вернёт false в переменную ok, а в c запишет 0

6. false = строка не является корректным целым числом, а в out - записывается 0.

7. TryParse стоит использовать всегда, когда входные данные могут быть некорректными
